# Multi-Core CRM Platform 👋
![Version](https://img.shields.io/badge/version-v1-blue.svg?cacheSeconds=2592000)

> Full-stack Customer Relationship Management system for multi-business and multi-customer workflows, with Java Spring Boot backend and React TypeScript frontend, JWT authentication, and role-based access control (RBAC).

## Key Features
- Core CRM: Customer & Lead Management, Deal Tracking, Pipeline & Activity Timeline
- Sales & Analytics: Sales Funnel, Revenue Stats, Business Growth Charts
- Support & Admin Tools: Ticketing System, SLA Tracking, Multi-tenant Support, Admin Dashboards
- Customer-Facing Tools: Customer Portal, Appointment View, Ticket Creation

## Tools & Technologies
- **Backend:** Java Spring Boot, JWT, RBAC
- **Frontend:** React, TypeScript
- **Database & API Testing:** PostgreSQL - Supabase, Postman
- **Development:** IntelliJ IDEA, Git, GitHub
